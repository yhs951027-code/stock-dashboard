출발은 각자, 시작은 현지에서. 천안·인천·진해에서 따로 출발하니 1일차는 청천면 카페에서 모였다가 15시 체크인하는 흐름으로 짰어. 출발지별 이동 시간은 지도 앱에서 각자 확인해야 해.

이번 여행의 핵심

  • 문광저수지 은행나무길: 여러 매체가 10월 하순~11월 초를 절정으로 꼽음 (2026년 실제 단풍 상태는 확인 필요)
  • 산막이옛길: 호숫가 숲길 산책, 입장 무료·주차 3,000원
  • 숙소 바비큐 2회: 반려견 동반 식사 문제를 가장 확실하게 푸는 방법

꼭 먼저 확인할 것 3가지

  1. 두 마리 모두 15kg 미만인지 (숙소 규정)
  2. 숙소에 반려견 2마리 동반 사전 문의 (규정상 필수)
  3. 식당은 반려견 동반 정보가 대부분 확인 안 됨 → 전화 확인 또는 포장

반려견 동반 표시 기준

두 마리 확인 완료 두 마리 동반 조건까지 확인된 곳

추가 확인 필요 '동반 가능' 표기는 있지만 마릿수·크기·좌석 조건 미확인, 또는 정보 없음

동반 불가·조건 불충족 규정상 동반 불가

이번 조사에서 '두 마리 확인 완료' 단계까지 간 곳은 없어. 숙소도 체중 조건 때문에 '추가 확인 필요'로 뒀어.

날짜별 일정

날짜를 누르면 그날 일정만 보여. 이동 시간은 실제로 재 보지 않아서 수치를 적지 않았고, 각 카드의 다음 장소 길찾기 버튼으로 확인하면 돼.

맛집 · 카페

2026년 3월 1일부터 식품위생법 시행규칙 개정으로 음식점·카페의 반려동물 동반 출입이 조건부로 허용됐어. 그래도 업소마다 다르니, 아래에서 '추가 확인 필요'인 곳은 방문 전에 전화로 꼭 확인해.

관광지 · 볼거리

일정에 넣은 곳과, 조사했지만 반려견 때문에 뺀 곳을 같이 정리했어.

반려견 동반 정보

장소별 동반 조건을 한 표로 정리했어. '동반 가능'이라고만 적힌 곳은 두 마리 모두 된다고 보지 않았어.

현장 매너 · 법적 기본

  • 외출 시 목줄 착용과 배변 수거는 기본. 산책로는 주말에 붐비니 목줄을 짧게.
  • 숙소 규정상 맹견·공격성이 강한 개는 입실 불가.
  • 국립공원은 지정 구간 외 반려견 출입이 제한돼. 국립공원 반려견 시범 구간(북한산·계룡산·가야산)에 속리산은 없음.

지도 · 길찾기

지도 API(키)를 쓰지 않고, 카카오맵·네이버 지도 검색 링크로 연결하는 방식이야. 페이지 안에 지도가 뜨지는 않고, 누르면 새 창에서 지도 앱/사이트가 열려. 링크 동작은 이 파일을 만든 환경에서 실제로 눌러보지 못했으니 처음 한 번 눌러서 확인해줘.

직접 길찾기

카카오맵 길찾기 URL은 출발지·목적지를 이름으로 넘기는 방식이라, 열린 뒤 후보 중 정확한 장소를 한 번 골라야 할 수 있어.
