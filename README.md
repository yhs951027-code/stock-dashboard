# 오늘의 주식 분석

한국·미국 대표 종목을 공개된 숫자로 점수화해 보여주는 페이지입니다.

- `index.html` — 화면과 점수 계산
- `data.json` — 매일 갱신되는 숫자 (화~토 아침)
- `shorts/` — 쇼츠 메이커 (영상 고르면 자막 또는 위아래 검은 띠+제목을 입혀 유튜브로 공유, 휴대폰에 앱으로 설치 가능). `shorts/studio/`는 비공개 저장소에 설치되는 처리 파일
- `notes/` — 메모장 앱 (체크리스트·그림·음성 녹음·메모지·달력, 휴대폰에 앱으로 설치 가능)
- `reviews/` — 구매 리뷰 (쿠팡에서 산 물건 리뷰를 블로그용·쿠팡용으로 칸 나눠 쓰고 칸별 복사, 휴대폰에 앱으로 설치 가능)

분석 결과는 투자 권유가 아니며 수익을 보장하지 않습니다.
